# Vernac 0.5.1

- **Template-only MVC routes.** A GET endpoint can select a Thymeleaf template
  with `render "about";` without calling a usecase. Usecase-backed routes can
  continue to supply a model. See the [MVC contract](../../contracts/inbound-mvc.md#pages-with-a-template-only).
- **HTTP and MVC endpoint access.** Use `access public;` or
  `access authenticated;` after `base`. The policy covers the whole adapter.
  The host application supplies the Spring Security filter chain and its
  authentication mechanism. See the [access contract](../../contracts/inbound-http.md#endpoint-access-with-spring-security).
- **IntelliJ support.** The editor highlights the access policy and completes its
  keyword and values. The plugin requires build `262.10968.63` or later. Its
  descriptor sets no maximum build.

Use matching 0.5.1 Maven and IntelliJ artifacts after publication. Source
checkouts of the release preparation use `0.5.1-SNAPSHOT`.
