Trying the local demo?
  1. Register a test address such as demo@example.test.
  2. In a second terminal in the project directory, run ./mvnw exec:java -Dexec.args=mail . On Windows, run .\mvnw.cmd exec:java "-Dexec.args=mail".
  3. Open the verification link in the local mail preview, choose a password and sign in to your workspace.
